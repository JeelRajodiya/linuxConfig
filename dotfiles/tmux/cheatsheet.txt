###########################
# TMUX CHEAT SHEET
###########################

Prefix: Ctrl-Space
All default tmux keybindings are preserved.
Below are custom additions and plugin bindings.

═══ CUSTOM ADDITIONS ═════════════════════

Window Management
  ^C          New window (current dir)
  H / L       Prev / Next window
  ^A          Last window
  ^W          List windows
  R           Reload config

Pane Splitting (current dir)
  v / |       Vertical split
  _           Horizontal split

Session / Utility
  ^D          Detach
  ^X          Lock server
  ^L          Refresh client
  S           Choose session
  K           Clear screen
  *           Sync panes (type in all)
  /           This cheat sheet

Copy Mode (vi-style, enter with [)
  v           Begin selection
  V           Rectangle toggle
  y           Copy selection

═══ PANE NAVIGATION (no prefix) ══════════

vim-tmux-navigator:
  Ctrl-h      Left pane
  Ctrl-j      Down pane
  Ctrl-k      Up pane
  Ctrl-l      Right pane

═══ PLUGIN BINDINGS ══════════════════════

TPM (plugin manager)
  I           Install plugins
  U           Update plugins
  M-u         Clean plugins

tmux-resurrect
  ^S          Save session
  ^R          Restore session

tmux-sessionx
  g           Go to session (zoxide)

tmux-floax
  F           Float panel
  P           Float menu

tmux-thumbs
  T           Thumbs mode (pick text)

tmux-fzf
  F5          Launch tmux-fzf

tmux-fzf-url
  u           Open URLs from pane

═══ USEFUL DEFAULTS (reminder) ═══════════

  c           New window
  n / p       Next / Prev window
  l           Last window
  w           Choose tree (windows+sessions)
  d           Detach
  x           Kill pane (confirm)
  z           Zoom pane
  "           Split horizontal
  %           Split vertical
  ,           Rename window
  .           Move window
  s           Choose session tree
  [           Copy mode
  ]           Paste buffer
  :           Command prompt
  ?           List all keybindings
  0-9         Select window by number
  Space       Next layout
  { / }       Swap pane up / down
  o           Cycle panes
  q           Display pane numbers
  ;           Last pane
  !           Break pane to window
  &           Kill window (confirm)
